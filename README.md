# 밈능검 — 밈 능력 검정시험(비공식) 📝

> **당신의 밈 감각, 몇 급입니까?**
> 매일 12문항 · 3분 완성 · 밈 연령 측정 · 전국 응시자 전원 동일 출제

**Live: https://mimneunggeom.netlify.app**

한능검(한국사능력검정시험)을 패러디한 데일리 밈 상식 아케이드.
**전부 지금 실제로 도는 밈만** 출제한다 — 2024 국민밈(갓생·중꺾마·럭키비키) / 2025 유행(야르·샤갈·밤티·동결건조) / 2026 최신(윤정아 챌린지·난리자베스·젬민이·셋로그)이
매일 4문항씩, 문항당 8→6→4.5초의 순발력 압박과 함께 출제된다.

결과는 **수능 성적통지표 패러디 이미지**(급수 + 칭호 + 밈연령 + 붉은 검인)로 발급되며,
Wordle식 무스포일러 이모지 그리드(🟩🟨🟥⬛)와 도발 문구로 단톡방 공유에 최적화되어 있다.
밈연령은 "옛날 밈을 알수록 늙음"이 아니라 **"최신 밈을 못 따라갈수록 늙음"**으로 측정한다.

## 왜 이 게임인가 (유행 전파 심리 설계)

사람들이 유행을 퍼 나르는 이유를 게임 장치로 번역했다:

1. **정체성 과시** — 급수·칭호·밈연령이 박힌 성적표 = "나는 이런 사람" 카드
2. **공통 화제** — 날짜 시드로 전원 동일 문제 → "오늘 7번 뭐냐ㅋㅋ" 대화 유발
3. **무스포 자랑** — 이모지 그리드는 정답을 노출하지 않으면서 호기심을 자극
4. **자기비하 유머** — "밈 화석", "N수생" 스탬프 → 저득점도 공유 소재가 됨
5. **도전장** — 공유 문구에 "넌 몇 급?" 자동 삽입 → 받은 사람이 다음 응시자
6. **스트릭** — 🔥 연속 응시로 손실 회피 심리 자극

> 밈은 1~2주면 식으므로 문항 풀은 분기마다 리프레시하는 것을 전제로 설계했다(식은 밈은 강등·삭제, 갓 뜬 밈을 최신 티어에 투입). 갱신 규칙은 [DESIGN.md](DESIGN.md) §5.

상세 설계는 [DESIGN.md](DESIGN.md) 참조.

## 실행

빌드 없음. 정적 파일 하나.

```bash
open index.html          # 또는
python3 -m http.server   # http://localhost:8000
```

- `?debug=1` — 제한시간 4배 + 정답 점선 표시 (테스트베드)
- `?exam=20260710` — 특정 회차 미리보기

## 구조

```
index.html      # 게임 전체 (마크업 + 스타일 + 엔진 + 문항 82개)
og.png          # 카톡/SNS 링크 미리보기 이미지
DESIGN.md       # 설계 SSOT
MONETIZE.md     # 수익화 실행 가이드 (AdFit/AdSense/게임포털)
steam/          # Steam 배포 준비 팩 (Electron 래퍼 + 절차)
```

## 문항 추가/제보

`index.html`의 `QUESTIONS` 배열에 추가 (c[0]이 정답, 렌더 시 자동 셔플).
**핵심**: 각 문항의 `t:"YYYY-MM"`(유행 시기)만 최신 날짜로 넣으면 된다 — 데일리는 **최근 2개 연도 밈만** 자동 출제하므로, 새 밈을 추가하면 편입되고 2년 지난 밈은 저절로 빠진다. 해가 바뀌면 기준도 자동으로 올라간다.
최신 밈 제보는 [Issues](https://github.com/znehraks/mimneunggeom/issues)로.
